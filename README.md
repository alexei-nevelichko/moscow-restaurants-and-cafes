# Исследование рынка общественного питания Москвы

> **Учебный проект курса «Аналитик данных» Яндекс Практикума.**

## Описание проекта

Исследование посвящено рынку общественного питания Москвы: структуре заведений, их распределению по административным округам, сетевому формату, рейтингам, количеству посадочных мест и ценам. Цель — выявить особенности рынка и сформулировать предварительные рекомендации для потенциального инвестора, рассматривающего открытие заведения.

**[Открыть исследование в Jupyter Notebook](moscow_public_catering_eda.ipynb)**

## Стек и инструменты

- **Python, pandas** — загрузка и объединение таблиц, предобработка и агрегация данных.
- **Matplotlib, Seaborn** — исследовательская визуализация.
- **Phik** — оценка связи между признаками.
- **Jupyter Notebook** — оформление хода исследования и выводов.

**Ключевые навыки:** `merge`, `groupby`, `agg`, обработка пропусков и дубликатов, выявление аномалий, сравнение долей, расчёт медиан, исследовательский анализ данных (EDA).

## Этапы исследования

1. **Загрузка данных.** Изучение двух таблиц с информацией о заведениях и ценах, объединение по идентификатору.
2. **Предобработка.** Проверка типов данных и пропусков, поиск дубликатов, обработка подозрительных значений посадочных мест, создание дополнительных признаков.
3. **Исследовательский анализ.** Распределение заведений по категориям и округам, сетевой формат, вместимость, рейтинги и крупнейшие сети.
4. **Анализ цен.** Сравнение ценовых сегментов и медианного чека по округам, проверка ограничений, связанных с неполными данными.
5. **Выводы.** Обобщение результатов и рекомендации для потенциального инвестора.

## Ключевые результаты

### 1. Структура рынка

- Наиболее распространённая категория заведений — **кафе (28,3%)**, далее следуют рестораны (24,3%) и кофейни (16,8%).
- Больше всего заведений находится в **Центральном административном округе (ЦАО)**.
- В ЦАО рестораны составляют **29,9%** всех заведений округа, тогда как по Москве в целом — **24,3%**. Разница составляет **5,6 процентного пункта**.

### 2. Сетевой формат

- Около **62%** заведений не относятся к сетям.
- Наибольшая доля сетевых точек внутри своих категорий у булочных (61,3%), пиццерий (52,1%) и кофеен (51%).
- В абсолютных значениях больше всего сетевых точек среди кафе (**779**), ресторанов (**729**) и кофеен (**720**). Это показывает, почему при оценке распространённости сетевого формата важно сопоставлять проценты и количество объектов.
- Самая крупная сеть в исследуемых данных — **«Шоколадница» (120 заведений)**.

### 3. Рейтинги

- Средние рейтинги категорий находятся в сравнительно узком диапазоне: **4,05–4,39**.
- Выше всего средний рейтинг у баров и пабов, ниже всего — у заведений быстрого питания.
- Более дорогие заведения в доступных данных в среднем имеют более высокий рейтинг, однако эта связь **не означает причинного влияния цены**: структура заведений по ценовым сегментам существенно различается.

### 4. Цены и расположение

- Среди всех заведений с известным средним чеком максимальная медиана отмечена в **ЦАО и ЗАО (1000 руб.)**, минимальная — в **ЮВАО (450 руб.)**.
- При сравнении только ресторанов самая высокая медиана в **ЗАО (1300 руб.)**, самая низкая — в **СВАО (837,5 руб.)**.
- Однозначного снижения чека по мере удаления от центра не выявлено.

## Рекомендации для потенциального инвестора

1. **Расположение и формат.** ЦАО — район с высокой концентрацией заведений и значительной долей ресторанов; до открытия важно отдельно оценить конкуренцию и стоимость аренды.
2. **Сетевой формат.** Кофейни и пиццерии можно рассмотреть для дальнейшего изучения: в обеих категориях сетевые заведения составляют более половины рынка в исследуемых данных.
3. **Ценовой сегмент.** При выборе позиции по цене важно учитывать не только округ, но и категорию заведения. Для ЮАО и ЮВАО имеет смысл отдельно изучить спрос на форматы с невысоким и средним чеком.
4. **Вместимость.** Медианное количество мест можно использовать как ориентир при первичной оценке помещения, но окончательное решение зависит от концепции, площади и бюджета.

## Ограничения исследования

- У **60,5%** заведений ценовая категория отсутствует (в данных обозначена как «Нет информации»). Часть показателей, связанных со средним чеком и вместимостью, рассчитана только по заведениям с известными значениями.
- Состав заведений с известным средним чеком отличается от состава всей совокупности. Например, в ЗАО доля ресторанов составляет 25,6% среди всех заведений, но 37,9% среди заведений с известным чеком. Это может влиять на сравнение округов.
- Некоторые сети представлены сразу в нескольких категориях, возможны неточности классификации отдельных точек.
- Выводы носят **описательный характер** и не заменяют исследование спроса, экономики бизнеса и конкретной локации.

## Как открыть и воспроизвести проект

1. Откройте файл [`moscow_public_catering_eda.ipynb`](moscow_public_catering_eda.ipynb) прямо на GitHub — сохранённые графики и таблицы доступны без запуска кода.
2. Для локального выполнения установите Python и Jupyter, затем зависимости: `pip install -r requirements.txt`.
3. Положите исходные файлы `rest_info.csv` и `rest_price.csv` рядом с ноутбуком. Код также поддерживает расположение `/datasets/`, используемое в учебной среде.
4. Выполните все ячейки ноутбука последовательно.

**Данные:** исходные CSV-файлы использовались в рамках учебного проекта и не включены в репозиторий до уточнения условий их распространения.
